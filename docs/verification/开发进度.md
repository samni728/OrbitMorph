## 产品与 MVP

核心用户是在 Mac 上频繁处理文件的人。主场景是从 Finder 拖动本地文件，用转盘选目标并在本地产出新文件。数据流为本地输入 → 已验证转换器 → 新文件；源文件保留。没有账号、支付、云端或 LLM 依赖。

## 1.1.0 格式扩展与仓库文档

按确认范围新增 SVG、WMV、WMA、SRT、VTT：识别格式从36增至41，路线增加41条。SVG只输入转PNG/JPG/WEBP/PDF；WMV/WMA按实际编码/容器能力门控输出与压缩；SRT↔VTT是原生UTF-8基础字幕转换。

同步输出格式列表与Subtitle分类目录，增加异常字幕、编码器缺失、参数接线和失败回滚回归。复杂字幕STYLE/REGION/cue settings拒绝转换，NOTE注释忽略；具体见格式覆盖与使用说明。

实际截图验收发现冷能力探测在SwiftUI布局内调用Process.waitUntilExit会重入run loop并崩溃；现将全部探测移到AppState初始化，界面读取快照/缓存。相关回归与六张实际应用截图已通过，截图日志无AttributeGraph重入报错。

补齐带截图README、USER_GUIDE、DEVELOPMENT、FORMAT_COVERAGE和capture-screenshots脚本；构建并验证1.1.0 app/DMG。V2的首次引导、中英文、仅菜单栏启动等仍是规划，未混入完成范围。

## 已知边界

无音轨视频的音频目标当前仍可显示，执行会报明确错误并清理产物；原生 ImageIO 后备只处理首帧；复杂文档版式受本机工具影响；ExFAT 回退尚未经过真实卷测试。当前 DMG 面向本机 Apple Silicon 验证，外部工具未随包分发，也未做 Apple Developer ID 公证。
